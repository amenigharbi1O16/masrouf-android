Masrouf - écrans UI (Welcome, Onboarding, Choix du compte, Inscription, Connexion)
Package : com.example.masrouf  |  Java + XML (AppCompat)

1) Copier app/src/main/java/com/example/masrouf/*.java dans votre package
2) Copier le contenu de app/src/main/res/ dans app/src/main/res/ (remplacer values/themes.xml,
   values/strings.xml, values/colors.xml ; supprimer values-night/themes.xml s'il existe)
3) Remplacer AndroidManifest.xml
4) Supprimer MainActivity.java + activity_main.xml (Hello World)
